🎯 Usage-Anchor 差分预测算法

Oxidra 拒绝使用粗暴的字符长度猜测，而是以前序请求的真实 Provider Usage 为绝对锚点： next_input ~= anchor.input_tokens + E(current_request) - E(anchor_request) 。 只有当压缩后真实重建请求低于 50% 目标且保留最新 2 个完整 Turn 时，才提交 Checkpoint。

Quick Start

快速安装与配置

支持 Windows 一键脚本部署或使用 Cargo 源码编译安装。

Windows 一键安装

MSVC Verified

自动下载最新 Windows MSVC 二进制包，校验 SHA-256 哈希完整性，并可自动添加到用户 PATH： 

irm https://raw.githubusercontent.com/post7794/oxidra/main/install.ps1 -OutFile $env:TEMP\oxidra-install.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File $env:TEMP\oxidra-install.ps1 -AddToPath

Cargo 源码编译

Rust 1.85+

克隆仓库并在本地以 Release 模式编译安装（支持 Linux、macOS 与 Windows）： 

git clone https://github.com/post7794/oxidra.git
cd oxidra
cargo install --path .

⚙ 初始配置与凭据设置

Oxidra 采用非对称安全设计：API 密钥存入系统原生 Keyring，通用配置存放于 config.toml：

1. 配置 API 凭据（保存至系统安全凭据库）
# 交互式无回显存入系统 Keyring
oxidra auth login

# 检查凭据健康状态
oxidra auth status
2. 首次运行体验 (支持批处理或单次指令)
# 单次执行模式
oxidra -p "运行单元测试并总结结果" --full-auto

# 启动交互式 REPL 会话
oxidra
