A FEW GOOD QUESTIONS

开始之前，
你可能想知道。

这是一个完全离线的 Agent 吗？

不是。Oxidra 在本地运行工具、保存会话和记忆，但模型推理通过 Responses API 完成，相关上下文会发送到你配置的 Provider。请求设置 store: false 不等于不联网，也不是对 Provider 数据政策的替代。

现在可以接入 MCP 工具吗？

还不行。MCP 的传输、配置、注册和持久协调内核已经实现，但 CLI、Agent 工具面和用户审批链路尚未接入。当前面向用户的是五个内置工具，而不是可安装的插件生态。

长上下文会自动压缩吗？

默认不会。需要显式传入 --experimental-auto-compact。checkpoint、历史回查和失败恢复已实现，但压缩质量证据仍绑定特定模型与后端，不能外推为所有模型的保证。

命令确认等于安全沙箱吗？

不等于。文件工具限定在项目根内，但 shell 命令拥有当前操作系统用户的权限。--full-auto 只跳过当前进程的 shell 逐次确认，不跳过记忆确认，也不能替代系统级隔离。
